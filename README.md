# cpsc_362_sp2025_group6
Title: Snake 6

Subtitle: As the snake grows, the challenges also grow

Project Description: We want to make a twist on the usual snake game. As the score grows and the snake increases in size, more challenges will be added to the game. This could mean a speed increase, walls spawing etc.

Styleguide: We will use the Python linter, Pylint, to format the project code. Pylint will check for errors in our code and will enforce a coding style to make sure that even though multiple different people will be coding, there will be consistency in the style of the code.
